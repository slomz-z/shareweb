Frequently Asked Questions

How does ShareWeb transfer files without size limits?

ShareWeb uses direct connections and high-speed local network streaming. Files stream straight between devices without being saved on cloud servers.

Is file sharing on ShareWeb encrypted and secure?

Yes. All file transfers use client-side AES-GCM and ECDH encryption derived from user master keys. File contents are encrypted directly in your browser before transmission.

Can I send files between iPhone, Android, Windows, and Mac?

Yes. ShareWeb runs seamlessly in any modern browser across iOS, Android, Windows, macOS, and Linux without requiring app store installations.

Do recipients need an account to receive files?

No. You can invite anyone via room code or instant link to receive files without forcing them to register.

Data we collect Email, name, profile photo (you provide), device fingerprint for security, and transfer metadata (counterparty, filename, size, timestamp). File contents are never stored or logged.
How we use it To show your identity to recipients, enforce rate limits, prevent abuse, and provide 30-day history. We never sell data or use it for advertising.
Your control Delete history locally anytime. Request full account deletion via email. Encrypted files are unrecoverable without your password — we have no backdoors.
