ShareWeb

LAN-First P2P File Transfer Protocol & Web Application

Active Development

ShareWeb is a modern real-time peer-to-peer file sharing platform engineered for zero-configuration, cross-device transfers with end-to-end security. Designed to operate seamlessly across both local networks (LAN) and wide-area networks (WAN).

✓ WebRTC Data Channels for direct browser-to-browser streaming
✓ Stateful Node.js WebSocket signaling server for peer discovery
✓ Zero-cloud storage model with optional encrypted relay fallback
✓ Responsive across 18+ mobile, tablet & desktop device viewports
