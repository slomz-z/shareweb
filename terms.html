2. Service Architecture & Zero-Knowledge Philosophy

ShareWeb provides fast, direct, and private file transfer capabilities with two primary operational modes:

  • Direct Local P2P: When devices share a local network, files transfer directly over WebRTC data channels with DTLS encryption without passing through intermediary storage.
  • Encrypted Server Relay: When peers reside on different networks, files are client-side encrypted and relayed via server memory buffers.

No Cloud Storage: ShareWeb is an instant transfer conduit, not a permanent cloud storage vault. Relayed file chunks are purged from server buffers immediately upon download completion or after 7 days of inactivity. Metadata in your transfer history is retained for 30 days.
